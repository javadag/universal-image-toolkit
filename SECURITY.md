# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Universal Image Toolkit, please do **NOT** open a public issue.

Instead, please send an email or submit a private security advisory through GitHub Security Advisories tab. All security vulnerabilities will be promptly investigated and patched.
